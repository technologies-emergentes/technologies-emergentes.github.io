# Utilisation de l'intelligence artificielle

L'utilisation en évaluation est permise à différent niveau selon le contexte du travail. Dans chaque consigne de travail je vous indique le niveau d'utilisation permis. 

Vous pouvez la questionner dans vos recherches mais ==je n'accepte pas== une réponse donnée par une intelligence comme étant une source valide.

Pour plus de détail sur les niveaux d'utilisation, consulter les ressources suivantes: 

- [Niveaux d'utilisation de l'intelligence artificielle](https://techinfo.profinfo.ca/niveaux-ia/){target=_blank}.
- [Citer les intelligences artificielles](https://techinfo.profinfo.ca/citer-ia/){target=_blank}. [En format PDF](https://cegepvicto.sharepoint.com/:b:/s/etudiants.420/ESEgA3D9aa9KoB62AC4SvgEBXFhzpX-BggsV4tRfr9nd-A?e=QIZjMe){target=_blank}
- La PDEA (article 11)

Peut importe le niveau d'utilisation, vous devez en tout temps: 

- comprendre votre code et être en mesure de l'expliquer.
- citer l'utilisation de l'intelligence artificielle dans vos travaux selon les normes décrites plus haut.

Tout manquement à ces comportements peut être sujet aux sanctions applicables (tricherie et plagiat, retrait de la classe ou refus de répondre aux questions). Si vous avez un doute, venez m'en parler
