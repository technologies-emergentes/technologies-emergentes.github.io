# Citer ses sources

Il est essentiel de bien citer ses sources dans nos différents travaux. Il existe plusieurs format de référence mais le plus commun est le format APA 7e édition. C'est celui que nous allons utiliser dans ce cours.

Il existe plusieurs outils pour vous aider à créer des références à ce format, en voici quelques uns.

- Présentation et guide pour le style APA : [https://mondiapason.ca/fr/presentation-du-style-apa](https://mondiapason.ca/fr/presentation-du-style-apa){target=_blank}
- Un générateur de référence en ligne : [https://www.citationmachine.net/](https://www.citationmachine.net/){target=_blank}
- Un logiciel de stockage de référence qui permet de les exporter au format désirer. Très pratique quand on fait des recherches : [https://www.zotero.org/](https://www.zotero.org/){target=_blank}
- Si vous voulez citer une intelligence artificielle, nous avons créé un petit guide : [https://techinfo.profinfo.ca/citer-ia/](https://techinfo.profinfo.ca/citer-ia/){target=_blank}
- Il est aussi disponible en téléchargement sur Teams dans le groupe étudiant : [Lien de téléchargement](https://cegepvicto.sharepoint.com/:b:/s/etudiants.420/ESEgA3D9aa9KoB62AC4SvgEBXFhzpX-BggsV4tRfr9nd-A?e=QIZjMe){target=_blank}
