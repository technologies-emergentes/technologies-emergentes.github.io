# Élaboration d’un projet avec une nouvelle technologie

Voici une série d'étapes que vous pourriez suivre dans l'élaboration de votre projet utilisant une nouvelle technologie.

## 1. Définir le projet

Déterminer clairement les objectifs du projet

**Questions à se poser:**

- Quel problème je veux résoudre?
- Qui seront les utilisateurs de mon projet?
- Quel est le résultat attendu?
- Quels sont les technologies que je peux utiliser pour réaliser se projet?

## 2. Découvrir la nouvelle technologie

Avant de commencer le développement, il est primordial de prendre le temps de se familiariser avec la technologie.

**Il faut s'assurer de comprendre: **

- Son fonctionnement général
- Ses principales fonctionnalités
- Ses avantages et ses limites
- Les types de projets pour lesquels la technologie est utilisée en général

## 3. Faire des recherches

Consulter différentes sources pour vous apprendre à utiliser la technologie

- Documentation officielle
- Tutoriels
- Exemple de projets
- Forums de discussions
- Vidéos de formation

## 4. Installer et préparer l'environnement de développement

Configurer les outils nécessaires au développement et se les approprier.

**Exemples**

- Installer le logiciel ou le framework
- Configurer l'environnement de développement
- Installer les bibliothèques nécessaires
- Créer un projet de test

## 5. Expérimenter avec la technologie

Créer de petits essais avant de commencer le véritable projet. 

C'est à cette étape qu'on va répondre à la question: 

> "Est-ce que la technologie que j'ai choisi est indiqué pour le projet que je veux réaliser?"

On peut tester individuellement les fonctionnalités importantes.

## 6. Créer une preuve de concept (prototype)

Développer une petite version permettant de tester les éléments les plus importants ou les plus risqués du projet.

**Exemple: **
Avant de créer une application complète en réalité virtuelle, créer une petite scène permettant simplement de tester les interactions avec les objets.

!!! note ""
    
    Cette preuve de concept viendra confirmer qu'on a choisi la bonne technologie.

## 7. Planifier le projet

Organiser le travail avant de commencer le développement complet.

Il faut notamment déterminer :

- Les fonctionnalités à développer
- Les priorités
- Les tâches à réaliser
- Les ressources nécessaires
- L'échéancier

## 8. Concevoir le prototype

Créer une première version du projet qui contient les fonctionnalités essentielles.

Le prototype permet de visualiser concrètement la solution et d'identifier rapidement les problèmes.

## 9. Tester et améliorer

Vous devez vous assurer que votre prototype fonctionne et réponds à vos besoins initiaux.

- Est-ce que toutes les fonctionnalités fonctionnent?
- Est-ce que la technologie répond aux besoins?
- Quels problèmes ont été rencontrés?
- Quelles améliorations sont nécessaires?

## 10. Développer la version finale

Une fois que le prototype a démontré que la solution est viable, poursuivre avec le développement plus complet du projet.

## 11. Évaluer le projet

À la fin, faire un retour sur l'expérience.

Questions importantes à se poser:

- Les objectifs ont-ils été atteints?
- La nouvelle technologie était-elle un bon choix?
- Quels problèmes avons-nous rencontrés?
- Qu'avons-nous appris?
- Que ferions-nous différemment la prochaine fois?
