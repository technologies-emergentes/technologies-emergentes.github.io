# Rapport de technologies émergentes

## Description globale

Vous avez à faire une courte recherche sur un sujet lié aux technologies émergentes.

**Apprentissages visés** : Cette évaluation est liée à l'élément de compétence suivant : 

- 00SH : S’adapter à des technologies informatiques
    - 1 - Effectuer une veille technologique.

## Consigne

Choisissez une technologie à votre choix qui vous intéresse. Vous devez trouver 3 articles sur le sujet écrits en 2026.

Ensuite dans un document Word: 

- Introduisez la technologie choisie et expliquer en quoi elle vous intéresse.
- Résumez les articles et fournissez les sources dans une bibliographie.
    - Dans le résumé expliquez au moins 3 points importants pour chaque article
- Rédigez un court texte où vous imaginez selon vous comment la technologie évoluera dans les 5 prochaines années :
    - Le texte doit correspondre à la technologie choisie.
    - Le texte doit démontrer une évolution logique de la technologie.
    - L'évolution doit se baser en partie sur les articles résumés.
- Une bibliographie avec vos sources au format [APA7](../notes/citations.md).
