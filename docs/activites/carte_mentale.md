# Carte mentale

## Description générale

À l'aide d'un outil en ligne vous devez créer une carte mentale qui explique le concept de carte mentale 😜.

## Consignes

**Choix de l'outil en ligne**

- Il y a une liste disponible à la fin de la [page de notes](../notes/carte_mentale.md) sur les cartes mentales.
- Vous pouvez très bien utiliser l'outils de votre choix

**Choix de la source**

Résumé dans votre carte mentale les informations contenues dans une de ces sources : 

- [La carte mentale : un outil pour soutenir l’apprentissage](https://www.alloprof.qc.ca/fr/enseignants/ressources-pour-enseigner/la-carte-mentale-un-outil-pour-soutenir-l-apprentissage-z0213){target=_blank}
- [Qu’est-ce qu’une carte mentale ?](https://miro.com/fr/carte-mentale/qu-est-ce-qu-une-carte-mentale/){target=_blank}
- [Carte mentale - Explications](https://www.ebsi.umontreal.ca/jetrouve/projet/cartes_m/mental_1.htm){target=_blank}

## Remise

Retournez votre carte mentale dans le devoir Teams de l'exercice soit au format image ou en me partageant le lien pour que je puisse la consulter.
