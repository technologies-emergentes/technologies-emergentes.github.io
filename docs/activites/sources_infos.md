## Utilisation de Zotero

Nous allons installer et configurer Zotero pour ensuite créer nos premières références.

### Installation et configuration

1. Rendez-vous sur le site [https://www.zotero.org/](https://www.zotero.org/) pour télécharger et installer Zotero.
2. Installez aussi le connecteur pour le navigateur que vous utilisez.
3. Créez un compte sur le site de Zotero et synchronisez l'application avec votre compte.

### Création de références

1. Ouvrez Zotero sur votre portable.
2. Créez dans votre bibliothèque un nouveau répertoire intitulé "Technologies émergentes"
3. Rendez-vous sur le site [https://docs.zotero-fr.org/quick_start_guide/#](https://docs.zotero-fr.org/quick_start_guide/#){target=_blank} et avec le connecteur installé dans votre navigateur créer une référence pour ce site dans le répertoire "Technologies émergentes" de votre bibliothèque.
4. Créer maintenant une référence bibliographique au format APA7 pour cette source et copier là dans le presse papier.
5. Coller ensuite votre référence dans un document texte, vous devriez avoir ce résultat : 

```
Guide rapide—Documentation Zotero Fr. (s. d.). Consulté 13 août 2024, à l’adresse https://docs.zotero-fr.org/quick_start_guide/#
```
